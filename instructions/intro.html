Welcome!

In this study, you will use a reading interface designed to support reading comprehension. The interface displays written text and provides corresponding sign language video support.

The interface includes several settings that control how the sign language video is presented and how the written text and video interact.

Before you begin using the reading interface, we will briefly introduce these settings using visual examples. You will see examples of:

  1. Location: where the sign language video appears on the screen.
  2. Video Segmentation: how much of the sign language video is shown, such as a word, sentence, paragraph, or the full text.
  3. Linking Granularity: how portions of the written text correspond to positions within the sign language video.
  4. Navigation: how the written text and sign language video can be used to navigate between one another.

You will first review examples of these options. Afterward, you will have an opportunity to use the reading interface yourself.
